# Учебный портал «Проекты»

Веб-приложение для управления проектами, сметной документацией и заказами, выполненное в качестве тестового задания.

---

## Реализованные требования ТЗ

1. **Учебная страница «Проекты» со списком:**
   - Карточки проектов с отображением названия, описания, статуса, сметы/бюджета и даты добавления.
   - Динамический счетчик общего количества проектов.
2. **Поиск:**
   - Живой поиск (live search) в реальном времени с фильтрацией по названию и описанию.
   - Кнопка быстрой очистки поискового поля (`✕`).
   - Дополнительный фильтр по статусу («В работе», «Планирование», «На согласовании», «Завершён»).
3. **Кнопка «Создать проект» и форма:**
   - Кнопка открывает модальное окно с формой.
   - Поля: название (обязательное, валидация длины), описание, статус, смета/бюджет.
   - Валидация на стороне клиента и сервера, защита от некорректных данных.
   - Уведомления (Toast) об успешном сохранении или ошибках.
   - Возможность удаления проектов с подтверждением.
4. **Сохранение после обновления:**
   - Данные сохраняются в базу данных **SQLite** через **Flask REST API**.
   - **Hybrid Storage:** если сервер запущен, данные пишутся в БД; если проект открыт как автономный HTML-файл без бэкенда, система автоматически и прозрачно переключается на **`localStorage`**.
5. **Адаптивность (на мобильных устройствах поиск и кнопка не перекрываются):**
   - На экранах телефонов (`max-width: 680px`) панель управления перестраивается в строгий вертикальный стек (`flex-direction: column; align-items: stretch`).
   - Поле поиска, фильтр и кнопка «Создать проект» занимают 100% ширины с фиксированным расстоянием (`gap: 12px`), что физически исключает взаимное наложение элементов при любых разрешениях экрана.

---

## Стек технологий

- **Backend:** Python 3.10+, Flask, Flask-SQLAlchemy, SQLite
- **Frontend:** Чистый HTML5 (семантика), Vanilla CSS (Flexbox, CSS Grid, custom properties, анимации), Vanilla JavaScript (ES6+, Fetch API, LocalStorage fallback)
- **Стилизация:** Современный интерфейс без тяжелых CSS-фреймворков для демонстрации чистого владения CSS.

## Запуск проекта

### Вариант 1: Полный стек (Flask + SQLite) — Рекомендуемый

1. Склонируйте или откройте папку проекта в терминале:
   ```powershell
   cd "c:\Users\ivrag\Test Project"
   ```

2. Активируйте виртуальное окружение:
   ```powershell
   .\venv\Scripts\Activate.ps1
   ```
   *(Если окружение не создано: `python -m venv venv` и `.\venv\Scripts\pip install -r requirements.txt`)*

3. Запустите Flask-сервер:
   ```powershell
   python app.py
   ```

4. Откройте в браузере:
   ```
   http://127.0.0.1:5000
   ```
   *(База данных SQLite создаётся и наполняется стартовыми данными автоматически)*

---

### Вариант 2: Автономный запуск (Frontend + localStorage)

Если требуется проверить только интерфейс и логику работы без запуска Python:
* Просто дважды кликните по файлу `index.html` в корне проекта или откройте его в любом браузере.
* Приложение автоматически переключится на хранилище браузера `localStorage`.

## REST API Эндпоинты

| Метод | URL | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/projects` | Список проектов (поддерживает `?q=поиск` и `?status=статус`) |
| `POST` | `/api/projects` | Создание нового проекта (JSON: `{ title, description, budget, status }`) |
| `DELETE` | `/api/projects/<id>` | Удаление проекта по ID |
